# Supermarket Sales R Project (Units I–IV)

## Contents
- `R_Unit1_to_Unit4_Project.Rproj`: open this in RStudio.
- `main.R`: main entry point. Resolves the project root from the script location
  (works from any working directory) and runs every script in order.
- `data/supermarket_sales.csv`: supplied dataset, preserved without edits.
- `scripts/unit1.R` to `scripts/unit4.R`: unit-based course implementations.
- `scripts/course_concept_demos.R`: separate tiny teaching examples for matrix
  operations, joins, tidyr reshaping, factor conversion and missing values (not
  mixed into the sales dataset).
- `scripts/problem_statements.R`: seven distinct project questions with tests.
- `scripts/data_analysis.R`: integrated summaries and plots.
- `scripts/report_figures.R`: the seven figures embedded in the final report.
- `scripts/verify_results.R`: recomputes every reported number from the raw CSV
  and stops the run on any mismatch.
- `outputs/plots/`: figures made from the supplied CSV; regenerated by the run.
- `outputs/reports/`: CSV/TXT summaries, data-quality audits, inferential tests.
- `report/Supermarket_Sales_FA2_Report.docx` and `.pdf`: final submission report
  in the instructor's sample-report format (`Sample Report for FA2 Activity.docx`,
  kept unchanged in the parent folder).
- `oral_exam/viva_questions_and_functions.md`: viva prep.
- `reference_materials/original_SDAUR/`: supplied course materials.

## Run
1. Install R (4.x) and RStudio.
2. Open `R_Unit1_to_Unit4_Project.Rproj`.
3. Run `main.R` from the project root: `Rscript main.R` or source it in RStudio.
4. `requirements.R` checks `dplyr`/`ggplot2` (required) and `tidyr` (optional,
   used only by one toy demo); missing packages are installed from CRAN, and if
   installation is impossible the project continues with a clear warning for the
   optional package.
5. The dataset is loaded from `data/supermarket_sales.csv`; if that file is
   missing, the documented Windows location `D:/PCCOE/sem3/R/units/project/
   supermarket_sales.csv` is tried next. The file actually used is printed.
6. Inspect `outputs/plots/`, `outputs/reports/`, and `report/figures/` after the run.

## Interpretation cautions
- `Total = 1.05 × Quantity × Unit price` for every row; `Tax 5% = gross income =
  0.05 × cogs`; `gross margin percentage` is constant. Regressions on these
  columns demonstrate model fitting, not causal discoveries.
- Branch and City correspond one-to-one.
- Dates cover only 1 January to 30 March 2019.
- Analysis is observational; inferences are associative, never causal.
